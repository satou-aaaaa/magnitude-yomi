# マグニチュードよみ（magnitude-yomi）

2つの地震のマグニチュードを見て、エネルギーが何倍ちがうかを当てる1日5問の学習ゲーム。正解したら、出てきた文がマグニチュードと震度のどちらにあてはまるかも選ぶ。マグニチュードの数え方・震度とのちがい・記録と求め方の問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/magnitude-yomi/>

- 中身は気象庁の「震度・マグニチュード・地震情報について」<https://www.jma.go.jp/jma/kishou/know/faq/faq27.html> と「よくある質問（地震について）」<https://www.jma.go.jp/jma/kishou/know/faq/faq7.html> 、松江地方気象台の「地震の基礎知識」<https://www.data.jma.go.jp/matsue/mission/earthquake/jishin/jishin-basic.html> に書いてあることだけです。
- 何倍かは「0.2大きいと約2倍、1大きいと約32倍、2大きいと約1000倍」によります。3・4ちがうときの約3万倍・約100万倍は、約32倍と約1000倍をかけ合わせて計算した目安です。
- 問題に出る地震A・Bは練習のための例で、本物の地震ではありません（東北地方太平洋沖地震など名前を出した地震をのぞく）。地震のときの行動は、自治体や気象庁の案内にしたがってください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
